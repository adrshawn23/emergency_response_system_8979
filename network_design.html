Network Design

Network Model

Figure 50: Network Model

The Kalubihan Emergency Response System serves to enable easy communication and coordination between barangay personnel and people residing there when an emergency is occurring. It consists of the admin and staff computers that link via a switch to a main router that accesses the internet, to which both residents connect through a different switch also connected to the same router. The router will be the central point for directing all network traffic to a web server via the internet. The web server has an emergency response application whereby both the personnel and the residents can send and receive real-time notifications, control emergency data, and react accordingly. The system offers a centralized and stable communication interface to enhance public safety and emergency preparedness in the barangay.

Network Topology

Figure 51: Network Topology

The Kalubihan Emergency Response System will be implementing the star topology. The Star topology is constructed in which each node is separately connected to a central connection point like switch or hubs. The benefits of a star network topology are extremely reliable, high-performance servers as there is no chance of data collisions. Kalubihan Emergency Response System employs the Star topology due to the topology is centralized connection and simple to manage. Through the implementation of this network topology, this does not affect other computer connections in case there is a failure action. This network topology is easier to maintain the network due to the central connection between hub and a node.

Development Phase

Technology Stock Diagram

The Kalubihan Emergency Response System is built on a three-layer technology stack consisting of the server side, front end, and back end. This architecture ensures the system remains scalable, secure, and capable of handling time-sensitive emergency data efficiently.

Figure 52: Technology Stock Diagram

The architecture of Kalubihan Emergency Response System is structured into three main layers: Server Side, Front End, and Back End.

  • The server side is implemented with Supabase (hosted API, authentication, and PostgreSQL database) to manage data flow. PostgreSQL stores resident details, incident reports, and response records, while Edge Functions support automation and real-time operations.
  • The front end is built with React/JSX, CSS, and JavaScript for structure, styling, and interactivity. JSON ensures smooth data exchange. Accessible via web browsers and mobile-responsive views for residents, responders, and administrators.
  • The back end handles application logic, data processing, and database interaction. Edge Functions manage server-side scripting, PostgreSQL ensures reliable storage, and row-level security with realtime subscriptions supports advanced processes like alerts and monitoring.

This layered approach ensures that Kalubihan Emergency Response System can process emergency reports in real time, deliver timely alerts, and maintain secure data handling. By clearly separating responsibilities across the technology stack, the system achieves both operational efficiency and ease of maintenance.
